# Enabling advanced Modify on Send extension

HCL Verse 3.2.2 allows the **Modify on Send** extension to modify the body of a mail.

This enhancement is disabled by default and can enabled by applying a notes.ini setting `VOP_GK_FEATURE_284=1`.
