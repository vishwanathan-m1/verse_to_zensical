# Enabling Domino Japanese eXtension name picker

In HCL Verse 3.2.6, for Japanese Domino installations that have enabled Domino Japanese eXtension \(DJX\), administrators can enable the use of the new DJX name picker for Verse users.

**Note:** The supported versions of Domino, for this feature are: 14.5 \(or higher\), 14.0FP2 \(or higher FP\), 12.0.2FP4 \(or higher FP\), 11.01FP9.

This feature is disabled by default and can be enabled by applying the notes.ini setting VOP\_GK\_FEATURE\_279=1 on the Domino server that runs Verse.

See [Using DJX name picker](../user/using_djx_name_picker.md) for the usage.
