# Meeting enhancements

HCL Verse 3.2.1 provides the following features and enhancements related to meetings.

## Dynamic online meeting services

Available from HCL Verse 3.2.1 onwards, users can generate a dynamic link to meetings on the following services - GoToMeeting, Microsoft Teams, WebEx, Zoom, and Sametime.

For more information, see [How do I integrate an online meeting?](../user/faq_online_meeting_integration.md) in user documentation and [Enabling dynamic online meeting services](../admin/enabling_domi_online_meetings.md) in admin documentation.

## Confirm meeting

Beginning with HCL Verse 3.2.1, the chair of a meeting can Confirm the meeting. Confirm Meeting is a calendar workflow action that is available to the Chair of the meeting \(or the Chair’s delegate\) in the context of the event-form. For more information, see [Confirm meeting as a chair](../user/faq_calendar_bar_create.md#section_urj_ms5_s1c) in the user documentation.
