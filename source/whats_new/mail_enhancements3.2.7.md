## **Summarizing Emails with Domino IQ**  
Users can use Domino IQ (AI) to create a short, high-level summary of an email’s content, highlighting the key points without requiring the user to read the full email themselves.

To enable this feature, see [Enabling Domino IQ in Domino platform](../admin/enabling_dominoiqreply_summarize.md).  
To learn how to generate summaries, see [Summarizing Emails with Domino IQ](../user/dominoiq_summarize.md).

## **Have Domino IQ suggest a reply email** 
Users can use Domino IQ (AI) to create a helpful suggestion for their email responses. Users will have a Domino IQ Reply and Domino IQ Reply to All action available in the action bar of a Mail message.  

To enable this feature, see [Enabling Domino IQ in Domino platform](../admin/enabling_dominoiqreply_summarize.md).  
To learn how to generate reply, see [Have Domino IQ suggest a reply email](../user/dominoiq_reply.md).
