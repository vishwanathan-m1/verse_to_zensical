# Mail enhancements

HCL Verse 3.2.3 provides the following features and enhancements related to Mail.

## Save sent mail option

HCL Verse 3.2.3 provides a new setting in the Mail section which allows the users to save all sent messages, never save any, or choose to be prompted for each message sent.

For more information, see [How can I choose to save sent mail?](../user/faq_optiontosavemail.md).
