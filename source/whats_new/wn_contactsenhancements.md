# Contacts enhancements

HCL Verse 3.2.1 provides the following features and enhancements related to contacts.

## Group contacts

This release allows users to create, edit and delete groups in the Contacts application. Users can add or delete members in a group and send the group an email. For more information, see [Adding New Group](../user/faq_contacts.md#section_kny_pz5_s1c)
