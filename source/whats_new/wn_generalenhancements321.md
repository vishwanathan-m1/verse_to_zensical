# General enhancements

HCL Verse 3.2.1 has the following general enhancements.

## **About Verse** dialog box update

When a user opens the **About Verse** dialog box, now the server name and the user's email address appear in the dialog.

**Note:** The server name in the about dialog box only displays if the HCL Domino administrator sets the following notes.ini setting on the Domino server that runs Verse.

`VOP_ENABLE_SERVERNAME_IN_ABOUT=1`

## TinyMCE editor version update

TinyMCE editor version is upgraded to v6.7.3.
