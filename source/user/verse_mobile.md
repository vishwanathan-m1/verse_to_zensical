# How can I use Verse on my mobile device?

You can access HCL Verse® from the browser on your mobile device. You can also use Verse apps with an HCL Traveler server.

An improved experience is automatically available if you access Verse from a Safari or Chrome browser on a mobile device.

For more information on using HCL Verse apps with an HCL Traveler server, see **Using HCL Verse Mobile** in the [HCL Traveler documentation](https://help.hcltechsw.com/traveler/welcome/index.html).
