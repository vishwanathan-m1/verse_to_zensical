# How can I use {{ shortVerseProductName }} on my mobile device?

You can access {{ fullVerseProductName }}® from the browser on your mobile device. You can also use {{ shortVerseProductName }} apps with an HCL Traveler server.

An improved experience is automatically available if you access {{ shortVerseProductName }} from a Safari or Chrome browser on a mobile device.

For more information on using {{ fullVerseProductName }} apps with an HCL Traveler server, see **Using {{ fullVerseProductName }} Mobile** in the [HCL Traveler documentation](https://help.hcltechsw.com/traveler/welcome/index.html).
