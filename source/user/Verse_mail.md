# How do I master mail?

-   **[How do I mark mail that I need to follow up on?](../user/faq_mark_needs_action.md)**    
    {% if isDominoWorkspace %}
    Users can use the Summarize action in the action bar of a Mail message to display a summary of the message. When you receive a mail message that contains an action item, you can add it to a list of things that need to be completed, called **Needs Action**. You can also specify a date for when the action item needs to be completed, to further organize your work flow. 
    {% else %}
    Starting in HCL Verse 3.2.7, Verse users will have a Summarize action available in the action bar of a Mail message. When you receive a mail message that contains an action item, you can add it to a list of things that need to be completed, called **Needs Action**. You can also specify a date for when the action item needs to be completed, to further organize your work flow. 
    {% endif %}  

-   **[How do I track when someone owes me a response?](../user/faq_waiting_for.md)**    
{{ fullVerseProductName }} also gives you the ability to track responses from a mail message you have sent. You do this by marking the message as **Waiting For**. The mail then appears in a unique list in {{ shortVerseProductName }} so that you can easily keep track of whether or not you have received a response. 

-   **[How can mail rules help me organize my incoming mail?](../user/faq_mail_rules_0.md)**    
Mail rules help you direct the flow of your incoming mail by choosing actions to take based on conditions that you specify. You can see all the mail rules in the {{ shortVerseProductName }} setting.  

-   **[How do I organize all those mail threads?](../user/faq_threads.md)**   
{{ fullVerseProductName }} adds a graphical thread style to mail messages that lets you keep all your mail organized and easily viewable within your inbox.  

-   **[How do I digitally sign and encrypt my messages?](../user/Verse_encryptedmail.md)**    
When sending mail with {{ fullVerseProductName }}, you can add a digital signature and encrypt it for additional security.  

-   **[How do I add a signature to my mail messages?](../user/faq_signature.md)**    
You can add a signature to append to all your mail messages using {{ fullVerseProductName }}.  

-   **[How do I create and use Templates?](../user/faq_templates.md)**   
You can create new email templates with text or graphics and a recipient list that you can re-use for your mail messages. This is convenient when you frequently send a message, such as a status report, in the same format to the same people.  

-   **[Where are my drafts, sent mail, and templates?](../user/faq_drafts_sent.md)**    
Click the down arrow next to the Compose button to view recent drafts, sent mail, and templates. You can also see all drafts or all sent mail by clicking on "View All..." in the lower end of the dialogue.  

-   **[How to view MIME headers and MIME full content?](../user/mime_headers.md)**   
Click the ellipsis \(![this is the ellipsis icon](images/ellipsis.png)\) icon on the received messages and click the Show MIME Header or Show MIME Full action.

-   **[Summarizing Email with Domino IQ](../user/dominoiq_summarize.md)**   
Starting in HCL Verse 3.2.7, {{ shortVerseProductName }} users will have a **Summarize** action available in the action bar of a Mail message.  
{% else %}
Users can use the **Summarize** action available in the action bar of a Mail message to display a summary of the message.

    {% else %}

    {% endif %}

-   **[How can I view file attachments before I download them with {{ fullVerseProductName }}?](../user/preview_attachments.md)**   
    {% if isVerse %}

    {% else %}
    When someone sends you an attachment, you may be able to preview the contents of the attachment. 
    {% endif %}
  
{% if isVerse %}
-   **[How can I manage my archived mail?](../user/faq_archived_mail_.md)** 
You can view the messages in an archive mail file on a server, add messages to the archive, and restore messages from it. 
{% endif %}  

-   **[How can I recall a sent message?](../user/faq_recallmail.md)**    
You can now recall a sent message by clicking **Recall Message** from the overflow drop down menu. You can recall only one message at a time.  

-   **[How can I keep my mails private?](../user/faq_keepprivate.md)**    
When sending a mail with {{ fullVerseProductName }}, you can choose to keep the mail private.  

{% if isDominoWorkspace %}
-   **[How do I send file links and save mail attachments to Domino Workspace Files?](../user/how_do_i_send_file_links.md)**Instead of clogging up mailboxes with heavy attachments, users can send secure Files hyperlinks and offload incoming files directly to your Domino Workspace Files.
{% endif %}
-   **[How do I manage the address I send emails from?](../user/how_do_i_manage_sent_from_mails.md)**   
You can use an alternate address when sending mail from your mail file, from a shared mail file, or from a delegated mail file.  


-   **[How to search for emails from a user sent by a delegatee?](../user/how_to_search_emails_sent_in_deligation_mode.md)**
If you receive an email sent by a delegated user (for example, an executive administrator) on behalf of another user (for example, an executive), you can search for that email by searching for emails 'from' the executive.
