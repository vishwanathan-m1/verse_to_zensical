# How do I manage the address I send emails from?

You can use an alternate address when sending mail from your mail file, from a shared mail file, or from a delegated mail file.

**Note:** This feature requires Domino version 12.0.1 FP1 or higher. All mail files should use the Domino 12 mail template.

-   **[How do I use an alternate address when sending mail from my mail file?](../user/how_can_i_sent_mail_from_alias_addresses.md)**  
When using your mail file, you can send mail from any one of your alias addresses.
-   **[How do I use an alternate address when sending mail from a shared mail file?](../user/how_can_i_sent_mail_from_a_shared_mail_file.md)**  
If you choose a shared mail file \(mail-in database\), then you can pick an alternate address when sending an email.
-   **[How do I use an alternate address when sending mail from a delegated mail file?](../user/how_can_i_sent_mail_from_a_delegated_mail_address.md)**  
When you are a delegate for someone else's mail file, you can choose which of their alias addresses to use when you send mail on their behalf.
-   **[How to search for emails from a user sent by a delegatee?](../user/how_to_search_emails_sent_in_deligation_mode.md)**
